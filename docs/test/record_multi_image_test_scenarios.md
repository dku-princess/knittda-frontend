# 기록 사진 다중 선택 · 순서 재정렬 — iOS/Android 테스트 시나리오

대상 화면: 뜨개 기록 생성/수정 (`add_edit_record_screen.dart`)
관련 기능: 갤러리 다중 선택, 최대 5장 제한, 최대치 안내 다이얼로그, 롱프레스 드래그 재정렬

## 사전 조건 / 용어
- **최대 장수**: 5장 (`_maxImages`)
- **남은 슬롯(remaining)** = 5 − (기존 이미지 + 신규 이미지 수)
- 다중 선택은 **갤러리** 경로만 해당. **카메라**는 항상 1장.
- 플랫폼 동작 차이:
  - iOS: `pickMultiImage(limit:)`가 네이티브에서 **강제**됨 → 남은 개수 초과 선택 자체가 불가.
  - Android: 최신 Photo Picker에서 `setMaxItems`로 **강제**됨. 아주 구형/`GET_CONTENT` 폴백 환경에서는 무시될 수 있음(이때만 앱의 truncate+안내가 작동).
